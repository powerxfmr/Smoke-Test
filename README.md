# Timesheet Inspection Report Web

Open `index.html` in a browser to use the standalone web version.

## Usage

1. Select the month.
2. Fill in profile information.
3. Pick each day from the left list.
4. Fill working time, site, work description, remark, and customer/supervisor signature.
5. Use `Export Excel` to download an Excel-compatible `.xls` file.
6. Use `Export PDF` and choose `Save as PDF` from the browser print dialog.

Data is saved in the browser with `localStorage` on this computer.
